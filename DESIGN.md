# DESIGN.md

Visual rules for the eco web GUI (style B: neutral and clean). Read this before any UI work.
The layout reference is `docs/design/gui-layout.html`.

## Tokens

| Token | Value |
|---|---|
| Background | `#f5f5f7` |
| Panel | `#ffffff` |
| Border | `#d1d1d6` |
| Text | `#1d1d1f` |
| Muted text | `#6e6e73` |
| Accent | `#0071e3` |
| Success | `#34c759` |
| Warning | `#ff9f0a` |
| Error | `#ff3b30` |
| Device bezel | `#262626` |
| E-ink screen | `#e9e9e4` |

## Type

- Font stack: `-apple-system, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`
- Base size: 14px

## Radii

- Controls: 6px
- Panels: 10px

## Rules

- One primary button per stage.
- Plain English copy. No hype, no emoji.
- Advanced settings stay collapsed.
- Light theme only in v1.
