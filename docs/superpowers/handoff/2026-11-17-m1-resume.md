## OpenCV crash (Apple silicon only)

- **The crash:**
  - The 258-page Bicara OCR run segfaulted at page ~200: exit 139, peak RSS 2.77 GB.
  - The crash report puts it in OpenCV 5.0.0: `cv::resize` → KleidiCV 26.03 `kleidicv_resize_generic_stripe_u8<2,3>`, called from RapidOCR's preprocessing in a worker thread.
  - It is non-deterministic. The pages 201–250 chunk passed when run alone.
- **The experiments:**
  - OpenCV 5.0 with `cv2.setNumThreads(1)` completed all 258 pages (2.83 GB).
  - OpenCV 4.12.0.88, whose macOS arm64 build has only the carotene HAL and no KleidiCV, completed all 258 pages (3.50 GB, under the 4 GB limit).
  - The machine was loaded during both runs, so their times are not comparable.
- **The decision:** the owner approved pinning OpenCV below 4.13 for every platform (R-54). Windows and Linux x64 never use KleidiCV; they only move to the same version.
