# M2: Web GUI + Preview Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `eco web`. It is a local, single-user web GUI: one workspace that moves through *Select → Settings → Processing → Review & download*. It shows detailed progress, the original PDF page next to a device-size preview, and clickable findings.

**Architecture:**
- **Server:** FastAPI, with Jinja2 for the single page, plain CSS and vanilla JS (no build step, no CDN). Each conversion runs in a separate worker process, so Cancel can kill it, and its events are persisted to `events.jsonl` and streamed with Server-Sent Events.
- **Previews:** rendered server-side by a Typst page renderer. The book's Markdown is turned into Typst and compiled to one PNG per device page, along with a source-page map and a chapter list.

**Tech Stack:** M1 stack + `typst` (now a runtime dep), `fastapi`, `uvicorn`, `jinja2`, `python-multipart`; dev `httpx` (TestClient).

**Spec:** `docs/superpowers/specs/2026-11-16-epub-converter-optimizer-design.md` §8.9, §8.13, §8.2. Approved layout: `docs/design/gui-layout.html`. Visual rules: `DESIGN.md`. Prerequisite: M1 merged.

## Global Constraints

- Everything in M1's Global Constraints still applies.
- UI language English. All UI strings live in `src/eco/web/strings.py`.
- No external assets: system fonts only, no CDN. Response header `Content-Security-Policy: default-src 'self'; img-src 'self' data:; style-src 'self'; script-src 'self'`.
- Bind `127.0.0.1` by default without a token. Any non-loopback `--host` requires a token. If none is given, generate `secrets.token_urlsafe(24)` and print it.
- One conversion at a time. Others wait in the queue and show their position.
- Each conversion runs in a worker process (`multiprocessing` spawn context). Cancel must end it within 10 s.
- Jobs persist in `<data>/jobs/<id>/` and are deleted after `RETENTION_DAYS = 7`. Default upload limit `500` MB (`--max-upload-mb`).
- Uploads accepted: `.pdf`, `.md`, `.epub`. Anything else → HTTP 400 `Unsupported file type: <name>`.
- Core settings shown are exactly three: device, output files, file size. Firmware, OCR, layout mode, font size and title/author/language live under "Advanced settings".
- Preview "View as": `CrossPoint`, `CrossInk`, `Stock`. CrossInk renders like CrossPoint (approximation). Stock hides images and shows the box `Image not shown on stock firmware`. EPUB previews are labelled `Approximate preview`.
- Typst renders with `ignore_system_fonts=True`, using embedded "Libertinus Serif" (body) and "DejaVu Sans Mono" (code), so output is identical on all OSes.
- antislop + DESIGN.md: one primary button per stage, plain copy, no emoji, no hype.

## Review Focus

1. Uploading `report.docx` → HTTP 400 `Unsupported file type: report.docx`, shown inline under the drop zone (Task 6 test).
2. Upload above the limit → HTTP 413 `File too large (limit 500 MB)` (Task 6 test).
3. Submitting a second job while one runs → `queued` with `position == 1`, then it runs after the first finishes (Task 4 test).
4. Reloading the browser mid-conversion → `GET /api/jobs/{id}` plus SSE replay of `events.jsonl` restores stage, page progress and findings (Task 6 test).
5. Network mode: `/`, `/static/*`, SSE, previews and downloads all return 401 without the token. An upload named `../../x.pdf` is stored inside the job dir (Task 5 and 6 tests).

### Task 1: Markdown → Typst

**Files:**
- Modify: `pyproject.toml` (move `typst>=0.15` from dev to dependencies; add `fastapi>=0.115`, `uvicorn>=0.32`, `jinja2>=3.1`, `python-multipart>=0.0.18`; dev `httpx>=0.28`), `uv.lock`
- Create: `src/eco/render/__init__.py`, `src/eco/render/md2typst.py`, `tests/render/test_md2typst.py`

**Interfaces:**
- Consumes: `BookSource` (M1 `eco.bookfolder`), `DEVICES`, `ImageProfile` (M1 `eco.options`), `transform_image` (M1 `eco.epub.images`).
- Produces:
  - `@dataclass(frozen=True) class RenderSettings: font_size: int = 32; margin: int = 16; line_height: float = 1.35; status_bar: bool = True`
  - `VIEWS = ("crosspoint", "crossink", "stock", "xtc")`
  - `to_typst(src: BookSource, *, device: str, settings: RenderSettings, view: str, image_profile: ImageProfile | None = None) -> dict[str, bytes | Path]`. Returns typst-py's multi-file input: `"main.typ"` (bytes) plus every referenced image path relative to `src.base_dir`.
    - With `image_profile`, images go through `transform_image` first (passed as bytes), so the preview shows the chosen file-size preset.
    - Every `#` heading starts a new page (`#show heading.where(level: 1): it => { pagebreak(weak: true); it }`), so a single chapter renders exactly like it does inside the whole book.
- Mapping (markdown-it tokens, the same parser options as the M1 builder):

  | Markdown element | Typst output |
  |---|---|
  | `#`…`######` | `=`…`======` |
  | paragraph / emphasis / strong / inline code | Typst equivalents, with text escaped for `\ # $ * _ ` < > @ [ ]` |
  | code fence | `#raw(block: true, "<escaped>")` |
  | `- item` | `- item` |
  | image | `#figure(image("<path>", width: 100%, fit: "contain"), caption: [...])` |
  | table HTML | parsed with `html.parser` into `#table(columns: n, ...)`; on `colspan`/`rowspan`, or on Xteink devices with > 4 columns, use the `table-image` twin |
  | `<!-- page: N -->` | `#context [#metadata((src: N, page: here().page())) <srcpage>]` |
  | each `#` heading | preceded by `#context [#metadata((title: "<title>", page: here().page())) <chap>]` |

  - In view `stock`, images become `#rect(width: 100%, stroke: 1pt + gray)[Image not shown on stock firmware]`.
- Preamble:
  - `#set page(width: Wpt, height: Hpt, margin: (x: m pt, top: m pt, bottom: (m + 22) pt))`, with a footer showing the current chapter title (left) and `counter(page).display() / counter(page).final()` (right) when `status_bar`.
  - `#set text(font: "Libertinus Serif", size: font_size pt, lang: <meta language>, hyphenate: true)`
  - `#set par(justify: true, leading: (line_height - 1) em)`
  - `#show raw: set text(font: "DejaVu Sans Mono", size: 0.62em)`
  - `general` uses 480×800.

### Task 2: Page renderer

**Files:**
- Create: `src/eco/render/pages.py`, `tests/render/test_pages.py`

**Interfaces:**
- Consumes: `to_typst`, `RenderSettings` (Task 1).
- Produces:
  - `@dataclass class Rendered: pages: list[bytes]; page_map: list[int]; chapters: list[tuple[str, int]]`
    - `pages`: PNG bytes, 8-bit grayscale, exactly the device size;
    - `page_map[i]`: source page shown on device page `i` (0-based list, 1-based source pages, 0 = unknown);
    - `chapters`: `(title, first device page 0-based)`.
  - `render_chapter(src: BookSource, *, device: str, settings: RenderSettings, view: str, source_page: int, image_profile: ImageProfile | None = None) -> tuple[Rendered, int]`.
    - Renders only the `#` chapter that contains `source_page`, decided by the last `<!-- page: N -->` marker ≤ `source_page`.
    - Returns the excerpt and the index of the excerpt page that shows `source_page`.
    - Used by live preview.
  - `render_book(src: BookSource, *, device: str, settings: RenderSettings, view: str, cache_dir: Path | None = None, image_profile: ImageProfile | None = None) -> Rendered`:
    - compile with `typst.compile(files, format="png", ppi=72.0, ignore_system_fonts=True)`;
    - query with `typst.query(files, "<srcpage>", field="value")` and `"<chap>"`;
    - convert each PNG to mode `L`;
    - when `cache_dir` is given, store `NNNN.png` + `map.json` there and reuse them if present.

### Task 4: Job store and runner

**Files:**
- Create: `src/eco/web/__init__.py`, `src/eco/web/jobs.py`, `tests/web/test_jobs.py`

**Interfaces:**
- Consumes: `convert_file`, `Options`, events (M1).
- Produces:
  - `RETENTION_DAYS = 7`
  - `@dataclass class JobFile: name: str; path: str; kind: str; outputs: dict[str, str]; book_dir: str | None; error: str | None`. `kind` is one of `pdf`, `md`, `epub`.
  - `@dataclass class JobInfo: id: str; status: str; created: float; options: dict; files: list[JobFile]; position: int`. `status` is one of `queued`, `running`, `done`, `failed`, `cancelled`.
  - `class JobStore(data_dir: Path)` with methods:
    - `create(uploads: list[tuple[str, BinaryIO]], options: Options) -> JobInfo` (names sanitized to `Path(name).name` with control chars removed, stored as `input/<n>-<name>`)
    - `rebuild(job_id: str, options: Options) -> JobInfo` (new job, inputs hard-linked or copied)
    - `get(job_id) -> JobInfo`, `list(limit: int = 20) -> list[JobInfo]`, `save(info) -> None`
    - `events(job_id) -> list[dict]`, `append_event(job_id, event: dict) -> None` (`events.jsonl`)
    - `purge(now: float | None = None) -> int`
  - `class Runner(store: JobStore, data_dir: Path)` with methods `start()`, `stop()`, `submit(job_id)`, `cancel(job_id) -> bool`, `subscribe(job_id) -> queue.Queue[dict]`, `unsubscribe(job_id, q)`.
  - Worker entry: `_work(job_dir: str, options: dict, data_dir: str, q: multiprocessing.Queue) -> None`. Runs `convert_file` per input and puts event dicts:
    - `{"type": "file", "index": i, "status": "started"|"done"|"failed", ...}`
    - `{"type": "stage", "stage": s, "status": ...}`
    - `{"type": "page", "done": d, "total": t}`
    - `{"type": "finding", "page": p, "kind": k, "level": l, "message": m}`
    - `{"type": "end", "status": "done"|"failed"}`
  - The runner thread processes the queue FIFO, one worker at a time. Cancel = `terminate()`, then `join(5)`, then `kill()`, then status `cancelled` and event `{"type": "end", "status": "cancelled"}`.
