# M1: Core + CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `eco`, a local CLI that turns PDF, Markdown, or EPUB into an EPUB optimized and compressed for a chosen Xteink model or a general e-reader, with an editable Markdown "book folder", model setup, findings, and a collaboration-ready repo.

**Architecture:** A pure-Python core library (`src/eco/`). The CLI is a thin wrapper over it. PDF goes through `pypdfium2` (page inspection, text, crops), then Docling (layout + OCR, behind one adapter module), then small fix-up passes, then a book folder (`book.md` + `images/`), then the EPUB builder, then the optimizer. CLI and (later) web call the same `convert_file()`.

**Tech Stack:** Python 3.12, uv, hatchling, Docling 2.150.1 (+ onnxruntime, RapidOCR), pypdfium2, Pillow, markdown-it-py + mdit-py-plugins, platformdirs, pytest, ruff, typst (dev: synthetic test PDFs).

**Spec:** `docs/superpowers/specs/2026-11-16-epub-converter-optimizer-design.md` (Indonesian). Spike evidence: `docs/research/2026-11-16-spike-pdf-engines.md`. Ground truth (local only): `samples/ground-truth/README.txt`.

## Global Constraints

- Python `==3.12.*` only; package manager `uv`; lockfile `uv.lock` committed; `.python-version` = `3.12`.
- Licenses: permissive only. Never add PyMuPDF/pymupdf4llm, ebooklib (AGPL), Calibre, pandoc, CREngine (GPL).
- Pin `docling==2.150.1`. List `onnxruntime>=1.23` explicitly (Docling does not pull it; RapidOCR fails without it). `torch>=2.13`. Constraint `setuptools>=84.1`.
- Linux installs torch/torchvision from `https://download.pytorch.org/whl/cpu` (never the CUDA build by default).
- Conversion opens **no network connections**: set `HF_HUB_OFFLINE=1` and `TRANSFORMERS_OFFLINE=1` and use local `artifacts_path`. Only `eco setup` downloads, after showing the size and getting a yes (`--yes` skips the prompt).
- Downloads: `HF_HUB_DISABLE_XET=1`, `HF_HUB_DOWNLOAD_TIMEOUT=20`, retry with resume, optional `--ipv4`.
- Model file allowlist: `.safetensors`, `.onnx`, `.npz` plus text/config (`.json`, `.txt`, `.yaml`, `.yml`, `.md`, tokenizer files). Reject `.pt`, `.pth`, `.bin`, `.pkl`, `.pickle`, `.ckpt`, `.joblib`.
- Devices: `x4`, `x4-pro`, `x4-classic` = 480×800; `x3` = 528×792; `general` = no fixed screen.
- Xteink EPUB rules: images baseline JPEG or PNG only, grayscale, fit the device screen (never upscale), alpha flattened to white, images under 20 px removed, no embedded fonts or `@font-face`, no GIF/WebP/TIFF/SVG (SVG cover wrappers unwrapped to `<img>`), no `float`, `position`, `display:flex|grid|inline-flex|inline-grid`, `columns`, `column-count` CSS, chapters ≤ `100_000` bytes of XHTML (provisional, verify on device).
- Every EPUB zip: `mimetype` first, `ZIP_STORED`, content `application/epub+zip`; all other entries `ZIP_DEFLATED` level 9; no `.DS_Store`, `Thumbs.db`, `__MACOSX/`, `desktop.ini`.
- English for code, comments, CLI text, findings, commit messages. `README.md` (English) + `README.id.md` (Indonesian).
- Never commit `samples/`, or any `*.pdf|*.epub|*.xtc|*.xtch` outside `tests/fixtures/` (CI guard).
- Never overwrite an input file with an output.
- Plugins: follow ponytail (smallest working change, stdlib first, no speculative abstractions) and antislop rules.
- Shorthand used in all four plans: "Steps 2–4: FAIL → implement → PASS" means:
  1. run `uv run pytest <the task's test files> -v` and see the new tests fail;
  2. implement;
  3. run the same command plus `uv run ruff check` and see everything pass.

## Review Focus

1. Optimizing `book.epub` into the same folder would overwrite the original → output is named `<stem>.<device>.epub`, and if that equals an input path a `-1` suffix is added (Task 18).
2. File names with spaces and non-ASCII (`Bicara itu ada seninya - Oh Su Hyang.pdf`, `Ü.pdf`) and Windows paths → work end to end (Task 18).
3. Password-protected PDF → clear error `PDF is password-protected: <name>`, exit code 1, no traceback (Task 9 + Task 18).
4. One corrupt file in a batch → the other files still convert; summary lists the failure; exit code 1 (Task 18).
5. Markdown referencing a missing image → finding `missing_image`, the EPUB is still built without it (Task 6).

### Task 5: Book folder I/O

**Files:**

**Interfaces:**
- Consumes: `Book`, `Block`, `Finding` (Task 4).
- Produces:

  - code: fenced with ```` ``` ````, or `~~~` if the text contains ```` ``` ````.
  - table: `<!-- table-image: images/… -->` followed by the HTML on its own lines.
  - image: `![alt](images/…)`, or `<figure><img src="…" alt="…"/><figcaption>…</figcaption></figure>` when there is a caption.
  - footnote: collected and emitted as `<p class="footnote">…</p>` before the next heading of the same or higher level.

### Task 6: EPUB builder

**Files:**
- Create: `src/eco/epub/__init__.py`, `src/eco/epub/zipio.py`, `src/eco/epub/builder.py`, `tests/epub/test_builder.py`
- Modify: `.github/workflows/ci.yml` (add the `epubcheck` job)

**Interfaces:**
- Consumes: `BookSource`, `load_source` (Task 5), `DEVICES`, `CHAPTER_LIMIT_BYTES` (Task 4).
- Produces:
  - `write_epub_zip(dst: Path, files: dict[str, bytes]) -> None`. Writes `mimetype` first (STORED); everything else deflate level 9, sorted by name.
  - `build_epub(src: BookSource, dst: Path, *, device: str) -> list[Finding]`
- Rules:
  - markdown-it `MarkdownIt("commonmark", {"html": True, "xhtmlOut": True}).enable("table")` plus `front_matter_plugin` and `footnote_plugin`.
  - One XHTML per `#` heading. Text before the first `#` goes to `text/front.xhtml`.
  - Split a chapter at block boundaries when its XHTML exceeds `CHAPTER_LIMIT_BYTES` (finding `chapter_split`).
  - Heading ids `h-<n>`.
  - `nav.xhtml` and `toc.ncx` with two levels (`#` and `##`).
  - OPF EPUB 3:

- Algorithm (from the spike):

```python
def is_multicolumn(blocks, width):  # text-like blocks narrower than 60% of width
    narrow = [b for b in blocks if b.bbox and (b.bbox[2] - b.bbox[0]) < 0.6 * width]
    left = [b for b in narrow if b.bbox[2] <= width / 2 + 6]
    right = [b for b in narrow if b.bbox[0] >= width / 2 - 6]
    return len(left) >= 2 and len(right) >= 2 and len(left) + len(right) == len(narrow)

def xy_cut(items, gap=6.0):  # items: blocks with bbox (x0, y0, x1, y1), top-left origin
    if len(items) <= 1: return items
    for lo, hi in ((1, 3), (0, 2)):  # horizontal bands first, then columns
        groups, end = [], None
        for b in sorted(items, key=lambda b: b.bbox[lo]):
            if end is not None and b.bbox[lo] > end + gap: groups.append([b])
            elif groups: groups[-1].append(b)
            else: groups.append([b])
            end = b.bbox[hi] if end is None else max(end, b.bbox[hi])
        if len(groups) > 1: return [x for g in groups for x in xy_cut(g, gap)]
    return sorted(items, key=lambda b: (b.bbox[1], b.bbox[0]))
```
