Supaya tetap mudah dipahami

  • Hanya satu tombol utama di setiap tahap. Tombol lain dibuat lebih samar.
  • Pengaturan lanjutan (font, margin, mode OCR) disembunyikan sampai dibutuhkan.
  • Memakai bahasa sehari-hari, misalnya "tabel lebar dijadikan gambar", bukan istilah teknis.
  • Penanda tahap bisa diklik untuk kembali. Konversi ulang memakai hasil baca PDF sebelumnya, jadi tidak perlu OCR ulang.
